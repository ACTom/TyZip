# TyZip 用户指南

TyZip 是 macOS 上的压缩包管理器：打开、浏览、创建、修改、解压、预览、搜索都在一个窗口里完成。
默认打开的是**文件管理器视图**，不会像「归档实用工具」那样自动解压。
系统要求：macOS 11 或更新版本。

遇到「为什么不行」的问题，先看 [FAQ](FAQ.md)。

## 打开与浏览

- 打开压缩包：`⌘O`、把文件拖进窗口，或在 Finder 里双击（常见压缩包类型已注册给 TyZip）。启动页会列出最近打开过的压缩包，并提供「浏览文件…」（选一个压缩包打开）和「浏览文件夹…」（进入文件管理器）。
- 没有打开压缩包时，窗口就是一个文件管理器，按 Finder 的习惯浏览磁盘。
- 打开压缩包后，包内目录以虚拟文件夹呈现，可以逐级下钻。左侧是包内目录树，右侧是 13 列详情。
- 13 列：名称、类型、大小、压缩后、压缩比、修改时间、创建时间、访问时间、属性、CRC、方法、加密、文件夹。点任意列头排序；文件夹行的大小是它下面所有条目的合计。
- 列表第一行固定是 `..`：在文件夹里是上一级，在压缩包顶层是离开压缩包。
- 内层压缩包：双击继续下钻。内层包是临时解出的副本，只能浏览和解压，离开时会清理。
- `.tar.gz`、`.tgz`、`.tar.bz2`、`.tar.xz`、`.tar.zst`、`.tar.lzma` 这类双层格式会自动解开外层，把里面的 tar 以只读方式打开；纯 `.gz`、`.bz2`、`.xz` 显示为单个文件条目。
- 分卷压缩包：直接打开 `.001`（`.002`、`.003` 也可以），TyZip 会把同一组卷当作一个包。
- 加密压缩包：打开时提示输入密码，输错可以重试，取消则保持原来的界面。解压和测试时同样会问密码。
- 面包屑保留压缩包打开前的路径，例如 `MacOS › Users › tom › file.zip › docs`。双击面包屑变成地址栏，可以输入绝对路径、`~/`、相对路径或包内路径（如 `/Users/tom/file.zip/docs/`），回车跳转，Esc 取消。
- 后退、前进、上一级在「前往」菜单，也有快捷键（见文末）。在压缩包里按 Esc 回到打开它时的文件夹，光标会停在那个压缩包上。
- 隐藏文件：视图 → 显示隐藏文件（作用于文件列表）。
- 名称过滤：导航栏右侧的筛选框，只过滤当前文件夹，不会跨目录。
- 打开大包、列举超大文件夹、解压、测试这些耗时操作都在后台进行，界面不会卡住；内容区会浮出进度卡片，带「取消」按钮。

## 预览窗格

- 开关：视图 → 预览窗格；筛选框右边也有显示/隐藏按钮。宽度拖动后会记住。
- 文本：后台读取，带行号，可以选中复制，只读，不会改到文件。
- 上限 2 MB：超过就只显示前 2 MB，末尾标「… 预览已截断」。
- 编码自动检测（BOM、UTF-8，否则按 GBK）；也可以手动切 UTF-8、UTF-16 LE/BE、GBK/GB18030、Big5、Shift-JIS、EUC-KR、Windows-1252。切换只是重新解码，不会重新解压。
- `Wrap` 控制自动换行；`Syntax` 选高亮语言，`None` 关闭高亮。能认出文件类型时会自动选好。
- 支持高亮的语言（按类别）：
  - C 系：C/C++、C#、Java、Kotlin、Swift、Rust、Go
  - 脚本：Python、Ruby、PHP、Perl、Lua、Shell、Batch/PowerShell
  - 其它语言：Pascal、Visual Basic
  - Web 与配置：HTML（含 Vue）、XML、CSS/SCSS/Less、JSON、YAML、TOML、INI
  - 文档与数据：Markdown、SQL、TeX、Diff、Makefile
- 图片：默认按比例适应窗口；有 `+`、`−`、`1:1`、`Fit` 按钮，滚轮缩放，拖动平移。上限 32 MB，超过直接提示太大。
- 二进制文件不会硬当文本打开，显示「无法预览」。
- 选目录、加密条目或解不出来的条目时，窗格显示对应提示（以实际界面为准）。
- 压缩包内的条目在后台临时解出后再预览，列表不会因为预览而卡住。

## 创建与修改

- 新建：`⌘N`，或文件 → 新建压缩包…，或右键文件/文件夹 → 添加到压缩包…
- 能创建的格式：7z、zip、tar、wim，以及单流压缩 gzip、bzip2、xz。单流格式选多个文件时会生成 `.tar.gz`、`.tar.bz2`、`.tar.xz`。多选文件新建时，默认文件名取它们所在的目录名（压缩包也放在该目录）。
- 常用选项：
  - 压缩级别：存储、最快、快速、标准、最大、极限
  - 方法：随格式不同，有 LZMA2、LZMA、PPMd、BZip2、Deflate、Deflate64、Copy
  - 线程数；7z 还有固实块
  - 字典大小、字长、passes（按格式显示）
- 密码：7z 可勾「加密文件名（7z）」；zip 可勾「AES-256 加密（仅 zip）」，不勾就是传统 ZipCrypto。密码需要输两次。
- 分卷：7z 和 zip 支持，大小可选 100 MB、700 MB、1 GB、4 GB、16 GB、50 GB，写出 `.001`、`.002`…
- 预设：对话框顶部可以套用保存过的参数组合，也可以把当前设置存成预设。
- 添加、删除：工具栏「添加」「删除」，或右键菜单。删除前会确认（可在设置里关掉确认）。
- 重命名：包内右键「重命名…」，只支持文件条目，文件夹不能改名。
- 只有可更新的包才能改。RAR、ISO、CAB、DMG 等只读格式，内层包，分卷包，`.tar.gz` 里的 tar，都只能浏览和解压。
- 原地改不了或想换格式时，用「转换」（见下）。

| 格式 | 读取 | 创建 | 备注 |
| --- | --- | --- | --- |
| 7z、zip、tar、wim | 支持 | 支持 | 7z/zip 可加密、可分卷 |
| gzip、bzip2、xz | 支持 | 支持 | 单流，没有目录结构 |
| `.tar.gz`、`.tgz`、`.tar.bz2`、`.tar.xz` | 支持 | 支持 | 内层 tar 只读 |
| `.tar.zst`、`.tar.lzma` | 支持 | 不支持 | 只读 |
| zst、lzma、lz、z | 支持 | 不支持 | 单流，只读 |
| rar | 支持 | 不支持 | 只读/解压/测试 |
| iso、cab、dmg、arj、lzh/lha、cpio、rpm、deb、apk、jar 等 | 支持 | 不支持 | 只读 |
| 分卷 `.001`、`.002`… | 支持 | 支持 | 仅 7z/zip 可分卷 |
| Office/OpenDocument、epub | 支持 | 不支持 | 需用「作为压缩包打开」 |

## 解压与测试

- 解压：工具栏「解压」，或右键「解压…」。有选中条目就解选中，没有就解全部。
- 拖拽解压：在归档列表选中文件或文件夹，直接拖到桌面或 Finder 的文件夹里。文件是拖到目标时才后台解出的（Finder 显示复制进度）；文件夹会先在临时目录准备好再拖过去，大文件夹可能需要等一下。
- 对话框里默认解到**压缩包所在文件夹**（内层包等没有磁盘位置的压缩包才用设置里的默认解压文件夹）；也可以选桌面、下载、文稿、压缩包旁边，或「选择…」（下拉里显示英文：Desktop / Downloads / Documents / Beside the archive）。可以勾「解压到以压缩包命名的新文件夹」。
- **智能解压**：对话框里勾「智能解压」，按包内结构自动决定落点，不再多套一层：
  - 根上只有一个文件夹 → 把它的内容直接摊到目标目录（`photos.zip` 里是 `photos/` → 目标里直接出现 `a.jpg`，不会变成 `photos/photos/`）；
  - **例外**：如果这个唯一的文件夹是 macOS bundle（`.app`、`.framework`、`.bundle` 等），保持原名整包解出，不摊平——`a.zip` 里是 `a.app/...` 时解出来还是 `a.app`，不会只剩 `Contents/`；
  - 根上只有一个文件 → 直接解出该文件；
  - 多个根条目 → 建一个以包名命名的文件夹（`photos.tar.gz` → `photos/`）；
  - `.tar.gz` / `.cpio.zst` / `.zip.zst` 这类单流包直接解到内层归档的目录树，而不是只丢出一个 `.tar`；
  - macOS 的 `__MACOSX/` 和 `.DS_Store` 既不参与判断也不解出来。
  「智能解压」与「解压到以压缩包命名的新文件夹」互斥：勾一个另一个就变灰。只选中部分条目解压时智能解压不可用（置灰，悬停有提示），因为它要按整包结构判断。
- 冲突：覆盖 / 跳过 / 两者都保留（默认「两者都保留」）。只影响这次要写的条目，目标文件夹里无关的文件不动。
- 其它勾选：「解压后打开目标文件夹」「删除源压缩包」（成功后才删，删不掉会提示）。加密包在对话框里输密码。
- 测试：工具栏「测试」，或右键「测试压缩包」，检查结构和 CRC，结果在状态栏和汇总里。
- 批量：在文件列表里多选压缩包，右键：
  - 全部解压到…（选一个目标目录）
  - 全部解压到此处
  - 各自解压到独立文件夹
  - 测试全部压缩包
- 批量解压会逐个包先列条目，再按冲突策略过滤或改名后解压；可以取消，取消后不再开始后面的包，最后汇总失败项。
- 解压和测试都能中途取消，取消后状态栏会写「已取消」，不会当成成功。

## 搜索

- `⌘F`，或编辑 → 在压缩包中查找…
- 范围：名称 / 内容 / 名称和内容
- 方式：包含 / 通配符（`*` 和 `?`）/ 正则表达式；可勾「区分大小写」
- 结果跨目录平铺显示，状态栏显示「找到 N 项」或「未找到匹配项」
- 结果会再按当前名称过滤；改筛选框会重新过滤
- 内容搜索会跳过大于 32 MB 的条目
- 后台执行，可取消；编辑 → 清除查找（或关闭压缩包）丢弃结果

## 转换与注释

- 转换：文件 → 转换为其他格式…，或右键压缩包 → 转换为其他格式…。目标只能是能创建的格式（7z、zip、tar、wim、gzip、bzip2、xz）。默认选另一种格式；密码和「加密文件名」沿用原包。不能和原文件同名，覆盖前会确认，完成后在 Finder 里定位到新文件。
- 注释：包内右键 → 压缩包注释…。能读取归档注释；zip 可以编辑保存，7z 只读（以实际界面为准）。内层包和只读格式只能看。

## 编辑回写

- 双击包内普通文件：临时解出，用系统默认程序打开。
- 在外部程序里保存后切回 TyZip，会提示「文件已修改，是否写回压缩包」，选「是」就重写这个包。
- 只打开看了一眼、没保存，不会提示。
- Office、OpenDocument 文件双击是交给对应应用，不走这条路径；要浏览内部用右键「作为压缩包打开」。

## Finder 集成

- 文件列表右键菜单：
  - 打开、打开方式（列出系统推荐的应用，默认程序排第一，最多 24 个，末尾「其他…」自己选）
  - 作为压缩包打开（任何文件都能试，包括 `.docx` 这种其实是 zip 的）
  - 解压到此处（只对认得出的压缩包显示）
  - 在 Finder 中显示、复制路径
  - 添加到压缩包…、添加到 `<名字>.<格式>`、分别添加到独立压缩包、转换为其他格式…，以及批量解压/测试
- 没有关联程序时不再报错，会弹出和 Finder 一样的应用选择面板。
- 7 个 Finder 服务，菜单名带 `TyZip:` 前缀，中文系统显示为 `TyZip: 添加到压缩包…`、`TyZip: 解压…`、`TyZip: 解压到此处`、`TyZip: 解压到 <名字> 文件夹`、`TyZip: 智能解压`、`TyZip: 用 TyZip 打开`、`TyZip: 添加到 <名字>.7z`、`TyZip: 分别添加到独立压缩包`（英文系统显示 `TyZip: Add to Archive…` 等）。用之前把 `TyZip.app` 放进「应用程序」并至少启动一次，然后在 Finder 右键 → 服务；Path Finder 等第三方文件管理器的「服务」菜单里也能用。
  `TyZip: 解压到 <名字> 文件夹` 会在压缩包旁边创建同名文件夹（如 `photos.zip` → `photos/`）再解压进去；`TyZip: 解压到此处` 直接解到压缩包所在目录。
  `TyZip: 用 TyZip 打开` 对任何文件都可用（包括没注册的后缀、其实是 zip 的文档、自解压 exe 等），会用压缩包视图打开它。
  如果右键 → 服务里没有 TyZip 的条目，到 **系统设置 → 键盘 → 键盘快捷键 → 服务** 里勾选 TyZip 的 7 项（服务被关掉时不会出现在菜单里）。
- 双击压缩包默认由 TyZip 打开；也可以把文件拖到 TyZip 窗口。

## 外观与设置

- 主题：视图 → 主题；外观：浅色 / 深色 / 跟随系统。即时生效，重启后还记得。
- 语言：设置… → 语言，或应用菜单 → 语言。首次启动跟随系统语言，切换后要重启 TyZip 才生效。
- 侧边栏默认隐藏（视图 → 侧边栏打开），预览窗格默认打开；两者的宽度都可以拖，会记住。
- 设置对话框里还能改：显示隐藏文件、文件夹优先、删除条目前确认、解压后打开目标文件夹、默认解压文件夹（压缩包没有磁盘位置时使用）、清理图标缓存。改完点「保存」。
- 新建压缩包会记住上次用的格式，下次新建默认用它（没选过就是 7z）。
- 菜单里的主题、外观、隐藏文件等开关立即生效并自动保存。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `⌘O` | 打开压缩包 |
| `⌘N` | 新建压缩包 |
| `⌘F` | 在压缩包内查找 |
| `⌘A` | 全选 |
| `Delete`（⌫） | 删除选中的压缩包条目（需确认） |
| `Return` | 打开选中的文件、文件夹或压缩包 |

| `⌘Q` | 退出 |

刷新没有快捷键，在「前往 → 刷新」。

## 已知限制

- RAR 只能读取、解压、测试，不能创建。
- 内层压缩包、`.tar.gz` 里的 tar、分卷压缩包都不能原地修改，只能浏览和解压。
- 只有 zip 能保存归档注释。
- 没有 SFX 创建、基准测试，也没有 Windows / Linux 版。
- 预览上限：文本 2 MB，图片 32 MB。
- 应用没有做 Apple 公证，第一次打开会被 Gatekeeper 拦截。

细节和解决办法见 [FAQ](FAQ.md)。
